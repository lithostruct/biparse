# Composite Combinators

This section describes combinators formed via composition of smaller parsers, forming the bread and butter of parser combinators.

These are largely separated into three distinct categories:
- [Sequencing combinators](./21_sequencing.md), which executes sequential parsing.
- [Alternative combinators](./22_alternatives.md), which executes speculative parsing and branching.
- [Repetition combinators](./23_repetition.md), which repeat parsing a predetermined number of times.

Check out their respective pages for more information!
